Home/Command reference

A practical field guide

Find the command. Understand the why.

Search common Linux commands by name or task. Every entry includes a plain-language purpose, syntax, an example, and a note about safe use.

Scope note: Linux includes thousands of commands, and available tools vary by distribution. This guide focuses on common learning commands, not every command that exists. For a real system, use man command and your distribution's documentation.

Showing all commands.

pwd

Navigation

Print the absolute path of your current working directory.

Syntax & options

pwd · usually needs no options for basic use.

Safe example

pwd

Sample output

/home/learner

Related & note

Related: cd, ls. It reports the shell's current location.

ls

Navigation

List files and directories.

Syntax & options

ls [options] [path] · -l details, -a hidden entries, -h readable sizes.

Safe example

ls -lah ~/Documents

Sample output

drwxr-xr-x  notes
-rw-r--r--  todo.txt

Related & note

Related: pwd, cd. Hidden names begin with a dot.

cd

Navigation

Change the shell's current directory.

Syntax & options

cd [path] · cd .. goes to the parent; cd ~ goes to your home directory.

Safe example

cd ~/Documents

Sample output

(no output on success)

Related & note

Related: pwd, ls. Confirm where you are with pwd.

mkdir

Files & folders

Create a directory.

Syntax & options

mkdir [options] path · -p creates missing parent directories.

Safe example

mkdir -p practice/week-1

Sample output

(no output on success)

Related & note

Related: rmdir, touch. Check the path before creating files.

touch

Files & folders

Create an empty file if it does not exist, or update timestamps.

Syntax & options

touch path · accepts one or more paths.

Safe example

touch notes.txt

Sample output

(no output on success)

Related & note

Related: mkdir, cat. It does not add text to an existing file.

cp

Files & folders

Copy files or directories to a new path.

Syntax & options

cp [options] source destination · -r copies directories recursively.

Safe example

cp draft.txt draft.backup.txt

Sample output

(no output on success)

Related & note

Related: mv, rsync. Check whether the destination already exists.

mv

Files & folders

Move or rename a file or directory.

Syntax & options

mv source destination · options such as -i can ask before overwriting.

Safe example

mv draft.txt final-draft.txt

Sample output

(no output on success)

Related & note

Related: cp. A move can replace an existing destination depending on options.

rm

Files & folders

Remove directory entries. This is not the same as moving a file to a recycle bin.

Syntax & options

rm [options] path · -i asks before each removal; -r is recursive.

Safe example

rm -i old-draft.txt

Sample output

remove old-draft.txt? (y/N)

Related & note

Related: rmdir. Destructive: verify the exact path; never test it outside the simulator.

cat

Text & search

Print the contents of one or more files to standard output.

Syntax & options

cat [path] · best for short text files.

Safe example

cat welcome.txt

Sample output

Welcome to the practice folder.

Related & note

Related: less, head, tail. Avoid printing secrets into shared logs.

less

Text & search

View a text file one screen at a time.

Syntax & options

less path · press q to quit in a real terminal.

Safe example

less /var/log/example.log

Sample output

(interactive file viewer)

Related & note

Related: cat, tail. Use only on files you are permitted to read.

head / tail

Text & search

Show the beginning or end of a file. Useful for a quick preview.

Syntax & options

head -n N path · tail -n N path show N lines.

Safe example

tail -n 20 app.log

Sample output

(last 20 lines of app.log)

Related & note

Related: less, grep. Logs can contain private data.

grep

Text & search

Search lines of text for a pattern.

Syntax & options

grep [options] pattern file · -i ignores case; -n includes line numbers.

Safe example

grep -n "TODO" notes.txt

Sample output

3:TODO: review this example

Related & note

Related: find, less. Quote patterns that contain spaces or shell characters.

find

Text & search

Search directory trees for files that match criteria.

Syntax & options

find starting-path -name pattern · quote wildcard patterns.

Safe example

find . -name "*.txt"

Sample output

./notes.txt
./week-1/summary.txt

Related & note

Related: grep, locate. Start in a directory you own or are allowed to inspect.

chmod

Permissions

Change permission bits on a file or directory.

Syntax & options

chmod mode path · symbolic modes or numeric modes such as 640.

Safe example

chmod u+x script.sh

Sample output

(no output on success)

Related & note

Related: ls -l, chown. Avoid broad recursive changes.

chown

Permissions

Change the owner and optionally the group of a file.

Syntax & options

chown owner[:group] path · often requires administrator privileges.

Safe example

chown learner:learners report.txt

Sample output

(no output on success)

Related & note

Related: chmod, id. Check ownership before changing it.

whoami

Users & processes

Print the effective username for the current session.

Syntax & options

whoami · no arguments needed.

Safe example

whoami

Sample output

learner

Related & note

Related: id, groups. Helpful before permission-sensitive tasks.

ps

Processes

Show a snapshot of selected running processes.

Syntax & options

ps [options] · aux is a common Linux process listing.

Safe example

ps aux

Sample output

USER PID %CPU COMMAND

Related & note

Related: top, pgrep. Inspect a process before taking action.

top

Processes

Display a live, interactive summary of running processes and resource use.

Syntax & options

top · press q to quit in a real terminal.

Safe example

top

Sample output

PID USER  %CPU  COMMAND

Related & note

Related: ps, free. This site describes output; the simulator does not monitor your device.

apt / dnf

Packages

Search or inspect software packages with the package manager used by your distribution.

Syntax & options

apt search name, apt show name; Fedora commonly uses dnf info name.

Safe example

apt search text-editor
dnf info example-package

Sample output

Package: example-package
Description: sample package info

Related & note

Related: apt, dnf. Installing or updating software changes a system; use official repositories and read prompts.

uname

System & storage

Print basic kernel and system information.

Syntax & options

uname [options] · -a prints several fields.

Safe example

uname -a

Sample output

Linux workstation 6.x ...

Related & note

Related: cat /etc/os-release. Kernel details alone don't identify a full distribution.

df

Storage

Report available and used space for mounted filesystems.

Syntax & options

df -h formats sizes for readability.

Safe example

df -h

Sample output

Filesystem  Size  Used  Avail
/dev/sample 80G   32G    44G

Related & note

Related: du. Results depend on mount points and permissions.

du

Storage

Estimate space used by a file or directory tree.

Syntax & options

du -sh path shows one human-readable summary.

Safe example

du -sh ~/Documents

Sample output

8.0K  /home/learner/Documents

Related & note

Related: df, ls -lh. Directory totals can differ from filesystem totals.

free

System & storage

Display memory and swap usage.

Syntax & options

free -h · -h formats values for readability.

Safe example

free -h

Sample output

Mem:  7.6Gi  2.1Gi  3.8Gi

Related & note

Related: top. Cached memory is often reclaimable; it is not necessarily unavailable.

ip

Networking

Inspect or manage network interfaces, addresses, and routes.

Syntax & options

ip address lists addresses; ip route shows routes.

Safe example

ip address show

Sample output

inet 192.0.2.24/24

Related & note

Related: ping, ss. This reference uses documentation-only sample addresses.

ping

Networking

Test reachability and round-trip timing using ICMP echo messages, where permitted.

Syntax & options

ping -c 3 host sends three requests on common Linux systems.

Safe example

ping -c 3 192.0.2.1

Sample output

3 packets transmitted, sample replies shown

Related & note

Related: ip, dig. Practice site output is simulated; only test systems you are authorized to use.

dig / nslookup

Networking

Query DNS records to learn how a name resolves.

Syntax & options

dig name A · nslookup name provides a simpler query.

Safe example

dig example.com A

Sample output

example.com.  300  IN  A  192.0.2.10

Related & note

Related: DNS lesson. 192.0.2.0/24 is reserved for documentation examples.

curl

Networking

Transfer data to or from a URL. It is commonly used to inspect an HTTP response.

Syntax & options

curl -I URL requests response headers.

Safe example

curl -I https://example.com

Sample output

HTTP/2 200
content-type: text/html

Related & note

Related: HTTP/HTTPS lesson. The practice terminal never performs live requests.
